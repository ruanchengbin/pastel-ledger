shield
核心安全原则：100% 浏览器本地 IndexedDB 存储

您的全部记账凭证、收支明细与自设规则均完整密封在当前设备的本地浏览器沙盒中，不会上传至任何云端第三方服务器。请注意：若主动彻底清理浏览器缓存数据或重装系统，可能会导致本地账本擦除，强烈建议您每周至少导出一次 JSON 归档文件。
